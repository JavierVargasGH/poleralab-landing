## Descripción

PoleraLab es una landing page de una tienda ficticia especializada en poleras de algodón premium con diseños urbanos exclusivos. El sitio incluye secciones de Hero, Features, Testimonios, Pricing y Contacto, construido con HTML5 semántico, Bootstrap 5 (CDN), CSS personalizado mobile-first y JavaScript vanilla.
